# Completed chart prices

Public charts use Yahoo Finance's daily SPY and BTC-USD price rows in `etf_daily_prices`. OHLC comes from the daily quote arrays, rounded to four decimals; `adjusted_close` remains the separate Yahoo adjusted-close value. The displayed candles use quoted OHLC. A price row never supplies a replacement score or changes a saved model decision.

The original SPY ingestion ran only with the pre-open daily score publisher at 12:30 UTC. Its source bars correctly stop before the session being scored. Consequently, the October 1 completed SPY bar was not stored after the October 1 close. Crypto's existing model job can save its current UTC day's developing quote; that row must not be displayed as a finished daily close.

`/api/cron/prices` independently obtains completed SPY and BTC-USD bars at a configured 00:15 UTC every day. It requires the configured cron bearer secret, uses uncached provider requests with bounded retries, and validates the instrument/timezone/complete OHLC/adjusted-close/volume. It fills absent verified bars in its ten-day fetch window, ignoring conflicts so an existing historical bar stays intact, and updates a changed existing row only for the latest completed date. It preserves existing technical indicators and creation timestamps. It imports no model, publication, email, or social-delivery logic. Provider failures and a provider latest date behind the expected exchange calendar date return an unsuccessful status with the actual provider date, while keeping stored history usable. Quote-only history remains available when score loading fails or no score has been published.

SPY timestamps are interpreted in America/New_York. The public reader accepts today's bar only after 16:15 New York time, a conservative 15-minute finality buffer after the regular close. Early-close days also wait until 16:15. Weekends and standard NYSE holidays are excluded; the provider determines which real bars exist. BTC daily bars use UTC and become eligible at the following UTC midnight, including weekends. No current partial bar is used as a final close. Public pages show a pending-close notice if the expected completed date has no stored bar.

The score/publication and original model source dates remain separate from the latest completed chart quote date. Charts span three calendar months ending at the newest actually available score or eligible candle, joined only on the exact date. A newer candle without a published score displays no score for that date. Existing visible-page/focus refreshes pick up new stored candles even if the score publication has not changed. Browsing a chart date preserves the active saved decision's date semantics.

Cron configuration runs in Production after the branch is merged and deployed. A successful Preview build or local route check does not prove that the scheduled Production invocation occurred. The once-daily schedule works within Vercel Hobby's daily execution limit; Hobby invocations can arrive up to 59 minutes after the configured time. It does not promise intraday or tick-based price updates. This change does not run a model publisher. The authorized October 1 correction inserted the missing SPY row and replaced the verified incomplete BTC raw quote with its completed provider bar; other price history and saved scores/briefings were preserved.

Focused checks: `node scripts/verify-completed-prices.cjs` and `node scripts/verify-daily-freshness.cjs`.
